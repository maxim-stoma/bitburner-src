# Научиться программировать на JavaScript

## Для начинающих программистов

Если у вас мало опыта в программировании или его нет совсем — ничего страшного!
Чтобы получать удовольствие от этой игры, вовсе не обязательно быть отличным программистом.
Наоборот, игра может помочь вам освоить базовые концепции программирования.

Вот несколько хороших материалов для начинающих по программированию и JavaScript:

- [Learn-JS](https://www.learn-js.org/en/Welcome)
- [programiz](https://www.programiz.com/javascript/get-started)
- [Speaking JavaScript](https://exploringjs.com/es5/)
  Книга довольно объёмная.
  Всю историческую часть можно пропустить.
  Рекомендуемые главы: 1, 7–18

## Для опытных программистов

В этом разделе собраны материалы для тех, у кого есть опыт программирования, но кто раньше плотно не работал с JavaScript.

Но сначала важно разобраться с терминологией вокруг разных версий JavaScript.
Кратко она разобрана в этой статье:

[WTF is ES6, ES8, ES2017, ECMAScript...](https://codeburst.io/javascript-wtf-is-es6-es8-es-2017-ecmascript-dca859e4821c)

Главное, что стоит из неё вынести: в ES6 (он же ES2015) появилось множество ключевых возможностей, которые повсеместно используются в современном JavaScript.
А значит, движки и интерпретаторы уровня ES5 будут падать, столкнувшись с этими возможностями.
Ниже станет понятно, почему это важно.

- [MDN Introduction to JS](https://developer.mozilla.org/en-US/docs/Web/JavaScript/A_re-introduction_to_JavaScript)
- [Eloquent JavaScript (ES6+)](https://eloquentjavascript.net/)
  Рекомендуемые главы: введение, 1–6
- [Modern JavaScript Tutorial (ES6+)](https://javascript.info/)
  Рекомендуемые главы: 2, 4–6
