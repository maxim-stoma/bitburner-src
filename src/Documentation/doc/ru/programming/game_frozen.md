# Игра зависла или застряла?

## Бесконечный цикл в скриптах

### Обзор

Если игра зависла или как-то застряла, самая вероятная причина — бесконечный цикл в вашем скрипте.
Чтобы выйти из зависания, запустите игру с `?noScripts` в URL:

[Ссылка для запуска без зависания](https://bitburner-official.github.io?noScripts)

В версии для Steam игру можно перезагрузить без запуска скриптов через пункт меню: Reloads => Reload & Kill All Scripts.

Если вы запускаете исполняемый файл из командной строки, используйте параметр `--no-scripts`.

### Как починить бесконечный цикл

Чтобы починить скрипт, убедитесь, что во всех бесконечных циклах есть `sleep()` или любая другая функция с задержкой вроде `hack()` или `grow()`:

    while(true) {
        // This is an infinite loop that does something
        ...
        await ns.sleep(1000); // Add a 1s sleep to prevent freezing
    }

Также убедитесь, что каждый цикл while действительно доходит до `await`-нутой функции или до `break`. Например, в следующем фрагменте функция `sleep()` есть, но ни до неё, ни до возможных условных выходов управление никогда не доходит, и игра повиснет:

    while(true) {
        let currentMoney = ns.getServerMoneyAvailable("n00dles");
        let maxMoney = ns.getServerMaxMoney("n00dles");
        if (currentMoney < maxMoney/2){
            await ns.grow("n00dles");
        }
        if (currentMoney === maxMoney){
            break;
        }
    }

Если текущие деньги `n00dles` составляют, скажем, 75% от максимума, скрипт не дойдёт ни до `grow()`, ни до `break`, и игра повиснет.
Добавление sleep, как в первом примере, или изменение кода так, чтобы `await`-нутая функция или `break` всегда достигались, предотвратит зависание.

Частый бесконечный цикл возникает при переписывании скрипта покупки серверов из руководства для начинающих: получается цикл while, в котором изменение условия само по себе условно:

    const ram = 8;
    let i = ns.cloud.getServerNames().length;

    while (i < ns.cloud.getServerLimit()) {
        if (ns.getServerMoneyAvailable("home") > ns.cloud.getServerCost(ram)) {
            const hostname = ns.cloud.purchaseServer("cloud-server-" + i, ram);
            ns.scp("early-hack-template.js", hostname);
            ns.exec("early-hack-template.js", hostname, 3);
            ++i;
        }
    }

Если у игрока сейчас не хватает денег на покупку сервера, условие `if` будет ложным, и до `++i` управление не дойдёт.
Так как в скрипте нет `sleep()`, а значение `i` не изменится, пока `if` не станет истинным, игра повиснет.
Добавление `sleep()`, до которого управление доходит всегда, предотвратит зависание.

### Используйте отладчик

Если найти бесконечный цикл не удаётся, воспользуйтесь кнопкой Pause в отладчике.

Сначала откройте встроенные инструменты разработчика браузера:

- Веб-версия:
  - Windows/Linux: Ctrl + Shift + I или F12
  - macOS: Cmd + Option + I
- Версия для Steam:
  - Меню: Debug => Activate
  - Горячая клавиша:
    - Windows/Linux: F12
    - macOS: Cmd + Option + I

В инструментах разработчика:

- Откройте вкладку Sources (Chrome/Safari) или Debugger (Firefox).
- Нажмите кнопку Pause. Обычно она выглядит так: ⏸ и находится в правой части вкладки Sources/Debugger.

Это приостановит выполнение, и вы сможете отладить бесконечный цикл. Стек вызовов тоже очень пригодится.

## Чёрный экран

Если окно игры становится чёрным, но сама игра не падает, причина в том, что запущено слишком много одновременных скриптов (игра работает в браузере, а каждая вкладка может использовать лишь ограниченный объём памяти, после чего падает).
В зависимости от того, какие скрипты запущены, и от вашего железа, это число варьируется примерно от 50000 до 100000 экземпляров (в версии 2.0.2; в предыдущих версиях оно было примерно в 5 раз меньше).
Чтобы этого не происходило, старайтесь максимально использовать многопоточность скриптов.

## Баг

В остальных случаях игра, скорее всего, зависла или застряла из-за бага.
О том, как сообщить о баге, читайте [здесь](../../../../../CONTRIBUTING.md#reporting-bugs).
