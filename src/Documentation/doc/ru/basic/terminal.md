# Терминал

Терминал — это эмулятор консоли, через который вы взаимодействуете с другими [серверами](servers.md) в игре.
Открыть его можно, нажав вкладку `Terminal` в навигационном меню слева (возможно, придётся сначала развернуть раздел «Hacking», чтобы увидеть вкладку `Terminal`).
Также Терминал открывается сочетанием клавиш Alt + t.

## Файловая система (каталоги)

В Терминале есть очень простая файловая система, помогающая раскладывать файлы по каталогам.
Учтите, что это **не** _настоящая_ реализация файловой системы: она почти целиком построена на манипуляциях со строками.
Поэтому некоторых возможностей реальных файловых систем в нашем Терминале нет. Например:

- Автодополнение по Tab не работает с относительными путями
- **Команды `mv` и `rm` принимают в аргументах только полные пути к файлам.**
  **С каталогами они не работают.**

Эти возможности обычны для файловых систем Linux, но в игру пока не добавлены.

## Каталоги

Чтобы создать каталог, достаточно назвать файл, указав полный абсолютный путь в стиле Linux:

    /scripts/myScript.js

Это автоматически создаст «каталог» с именем `scripts`.
Работает это и для вложенных каталогов:

    /scripts/hacking/helpers/myHelperScripts.js

Файлы в корневом каталоге не обязаны начинаться с косой черты:

    thisIsAFileInTheRootDirectory.txt

Обратите внимание: **создать или удалить каталог вручную нельзя.**
Создание и удаление «каталогов» происходит автоматически, когда вы создаёте, переименовываете или удаляете файлы в игре.

## Абсолютные и относительные пути

Многие команды Терминала принимают как абсолютные, так и относительные пути к файлу.

Абсолютный путь задаёт расположение файла от корневого каталога (/).
Любой путь, начинающийся с косой черты, — абсолютный:

    $ nano /scripts/myScript.js
    $ cat /serverList.txt

Относительный путь задаёт расположение файла относительно текущего рабочего каталога.
Любой путь, **не** начинающийся с косой черты, — относительный.
Для относительных путей работают и точечные обозначения в стиле Linux:

    . (одна точка) - текущий каталог
    .. (две точки) - родительский каталог

    $ cd ..
    $ nano ../scripts/myScript.js
    $ nano ../../helper.js

Подробнее о том, как задавать пути и ссылки в скриптах, см. [Скрипты](scripts.md).

## Разбор аргументов

При вычислении команды терминала аргументы сначала разбираются по пробельным символам (обычно по пробелам).
Каждый пробельный символ означает конец аргумента и, возможно, начало нового.
Для большинства команд терминала этого достаточно.

А вот при запуске скриптов бывают важны детали, особенно два момента:

- Кавычками можно обернуть один аргумент и заставить разобрать его как строку.
  Пробельные символы внутри кавычек не порождают новый аргумент.
- Всё, что может быть числом, автоматически приводится к числу, если только не заключено в кавычки.

Вот пример, показывающий, как эти правила работают.
Возьмём такой скрипт `argType.js`:

    export async function main(ns) {
        ns.tprint("Number of args: " + ns.args.length);
        for (var i = 0; i < ns.args.length; ++i) {
            ns.tprint(typeof ns.args[i]);
        }
    }

Если выполнить такую команду терминала:

    $ run argType.js 123 1e3 "5" "this is a single argument"

в Терминале мы увидим:

    Running script with 1 thread(s), pid 1 and args: [123, 1000, "5", "this is a single argument"].
    argType.js: Number of args: 4
    argType.js: number
    argType.js: number
    argType.js: string
    argType.js: string

## Цепочки команд

Несколько команд Терминала можно выполнить за раз, разделив их
точкой с запятой (;). Например:

    $ run foo.js; tail foo.js

Команды в цепочке **не** ждут завершения функций вроде `hack` или `wget`, поэтому результат не всегда будет таким, как вы ожидаете.

## Особенности

Если ваши скрипты отрисовывают в терминале или в окне tail-лога текстовое поле (например, `<input>`, `<textarea>`) с атрибутом
`autoFocus`, фокус может не переходить на него автоматически, как ожидается. Точнее, текстовое поле получает фокус, но
терминал может тут же его отобрать. Зависит от конкретного тайминга отрисовки.
