# Hacknet-ноды

Эта распределённая сеть компьютеров приносит вам пассивный доход.
Повышая уровень ноды, её RAM и количество ядер CPU, вы увеличиваете её заработок.
Также можно покупать новые ноды и расширять Hacknet — стоимость каждой следующей ноды растёт по мере роста сети.

**Hacknet-ноды приносят меньше денег, чем даже простые скрипты для взлома, и сами по себе не позволяют продвигаться по игре.**

Позже в игре открывается мощная модификация системы Hacknet — [Hacknet-серверы](../advanced/hacknetservers.md).
