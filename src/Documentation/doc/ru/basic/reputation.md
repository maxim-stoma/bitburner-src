# Репутация

Чтобы получать [аугментации](augmentations.md) от [фракций](factions.md), нужно заслужить их доверие.

Сделать это можно по-разному, но чаще всего — предлагая [фракции](factions.md) свои услуги.
Другой вариант — передавать ей разведданные, добытые в [инфильтрациях](infiltration.md).

При установке [аугментаций](augmentations.md) вся ваша репутация конвертируется в расположение (favor).
Расположение увеличивает скорость набора репутации с этой фракцией.

При достаточном расположении открываются пожертвования.
Пожертвования позволяют получать репутацию напрямую за деньги.
Без работы на фракцию.
Это особенно полезно, когда для аугментации нужно очень много репутации.
