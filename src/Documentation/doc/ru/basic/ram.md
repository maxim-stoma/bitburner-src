# RAM

В Bitburner объём RAM определяет, сколько [скриптов](scripts.md) может работать на [сервере](servers.md).

Увеличение количества потоков [скрипта](scripts.md) во столько же раз увеличивает его расход RAM, но одновременно увеличивает и эффективность ряда функций, таких как `ns.hack()`, `ns.grow()` и `ns.weaken()`.

Дополнительную RAM для домашнего компьютера можно купить у продавцов техники.
Также источником дополнительной RAM могут служить арендованные (облачные) и взломанные серверы.
