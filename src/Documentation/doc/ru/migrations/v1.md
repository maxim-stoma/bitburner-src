# Руководство по миграции на v1.0.0

В версии v1.0.0 несколько API изменились с потерей обратной совместимости.

Мигрируется автоматически (только для ns2):

- bladeburner.getActionTime теперь возвращает миллисекунды вместо секунд.
- getHackTime теперь возвращает миллисекунды вместо секунд.
- getGrowTime теперь возвращает миллисекунды вместо секунд.
- getWeakenTime теперь возвращает миллисекунды вместо секунд.
- hackAnalyzePercent переименована в hackAnalyze
- hackAnalyzePercent возвращает долю вместо процентов
- hackChance (не formulas.basic.hackChance) переименована в hackAnalyzeChance
- formulas.basic разделена на formulas.skills и formulas.hacking

Не мигрируется (иногда требуются правки вручную):

- getPlayer().hacking_skill переименовано в `hacking`
- то же самое для sleeves
- getPurchasedServers больше не позволяет запрашивать IP вместо имён хостов.
- getStats объявлена устаревшей, используйте getPlayer
- getCharacterInformation объявлена устаревшей, используйте getPlayer
- getServerRam объявлена устаревшей, используйте getServerMaxRam и getServerUsedRam
- getServerBaseSecurityLevel будет объявлена устаревшей без замены — она практически не используется.
- sleep больше нельзя вызывать одновременно из нескольких мест, для этого добавлена новая функция asleep.
- write возвращает промис (нужен await).
- scp возвращает промис (нужен await).
- free port, write, read
- write и read больше не работают с портами — для этого есть writePort и readPort.

При загрузке v1.0.0 игра применит ряд правил, чтобы всё поправить.
Игра никогда не меняет файл, не сделав предварительно резервную копию с именем `BACKUP_имяфайла.ext`; после этого
в скрипте будет изменено всё, что игра посчитает нужным изменить.
Каждая изменённая строка будет предваряться исходной строкой.

Файл `v1_DETECTED_CHANGES.txt` укажет на все файлы, в которых возможны проблемы.
