# Руководство по миграции на v2.0.0

В версии v2.0.0 ещё несколько API изменились с потерей обратной совместимости.

## Работа

Система работы переписана с нуля. Причина в том, что каждому виду работы требовались
свои кешированные переменные в основном объекте Player.
Это порождало множество багов и падений. Систему переработали так, чтобы избежать багов
и сделать добавление новых видов работы почти тривиальным.
Все виды работы выдают награду сразу. Останавливать работу, чтобы «зачислить» награды вроде репутации, больше не нужно.
У работы на фракцию и компанию больше нет ограничения по времени.
Работа на компанию больше не режет прирост репутации вдвое при досрочном уходе.
Для вступления во фракции компаний теперь нужно 400k репутации (было 200k).
Бэкдор на сервере компании снижает это требование до 300k.
Все виды работы, как правило, больше не отслеживают накопленные приросты опыта и репутации, поскольку те начисляются мгновенно.

## commitCrime

Преступления теперь зациклены: закончив одну кражу из магазина, вы без дополнительных действий начинаете следующую. Сигнатура функции не изменилась, а вот поведение — да. Также появился новый параметр 'focus'.

Причина в том, что все эти поля так или иначе входят в новое поле работы `currentWork`.
Часть этих значений к тому же попросту неактуальна.
Взгляните на новую функцию singularity.getCurrentWork:

Все поля, оканчивающиеся на `_mult`, перенесены в структуру `mults`.
Например: `getPlayer().hacking_skill_mult` => `getPlayer().mults.hacking_skill`

Навыки перенесены в структуру skills.
Например: `getPlayer().hacking` => `getPlayer().skills.hacking`

Опыт перенесён в структуру exp.
Например: `getPlayer().hacking_exp` => `getPlayer().exp.hacking`

HP перенесены в структуру hp.
Например: `getPlayer().max_hp` => `getPlayer().hp.max` или `hp.current`

`hasWseAccount`, `hasTixApiAccess`, `has4SData`, `has4SDataTixApi` удалены и заменены аналогичными функциями из stock.

## workForCompany

Аргумент 'companyName' теперь обязателен.

## getScriptIncome и getScriptExpGain

Раньше эти две функции при вызове без аргументов возвращали суммарное значение по всем скриптам. Из-за этого получалась странная сигнатура.
Если нужен суммарный доход/опыт по всем скриптам, используйте новые getTotalScriptIncome / getTotalScriptExpGain.

## scp

Два последних аргумента scp поменялись местами. Теперь сигнатура такая: scp(files, destination, optional_source)

## Singularity

Функции singularity верхнего уровня были объявлены устаревшими некоторое время назад в пользу пространства имён singularity.
Это значит, что вызовы вроде 'ns.connect' нужно поменять на 'ns.singularity.connect'

## stock.buy, stock.sell, stock.short

Эти функции переименованы в stock.buyStock, stock.sellStock и stock.buyShort, потому что 'buy', 'sell' и 'short' —
очень распространённые токены, которые сбивали с толку расчёт RAM.

## corporation.bribe

Возможность давать взятку акциями убрана. Теперь сигнатура такая: bribe(faction, money)
