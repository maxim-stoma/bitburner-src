# Инструменты и ресурсы

## Официальный репозиторий скриптов

Есть планы создать официальный репозиторий скриптов для Bitburner.
На данный момент это не приоритетная задача, и работа над ней ещё не начиналась.
Тем не менее, если вы хотите поделиться своими скриптами прямо сейчас, репозиторий находится [здесь](https://github.com/bitburner-official/bitburner-scripts) — присылайте пул-реквесты.
