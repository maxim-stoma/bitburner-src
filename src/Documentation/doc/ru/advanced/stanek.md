# Stanek

Эллисон слегка не в себе.
Но её особая [аугментация](../basic/augmentations.md) очень полезна, несмотря на все её ~~баги~~ особенности.
Дар (Gift) представляет собой сетку из клеток, в которую можно размещать тетрисоподобные фигуры — фрагменты.
Каждый фрагмент усиливает свой множитель персонажа.
Правда, сами по себе фрагменты не слишком сильны.

Чтобы увеличить мощность фрагмента, нужно вызывать функцию `ns.stanek.charge()`.
Чем больше потоков — тем больше мощность.

Есть также особые фрагменты-усилители (booster fragments), которые увеличивают мощность соседних с ними фрагментов.
