# Source-Files

Source-File — это постоянное улучшение, более мощное, чем [аугментации](../basic/augmentations.md).
Source-File выдаётся за уничтожение [BitNode](bitnodes.md).
В игре много разных [BitNode](bitnodes.md), и каждый [BitNode](bitnodes.md) при уничтожении даёт свой собственный Source-File.

Source-File можно улучшить, уничтожив соответствующий [BitNode](bitnodes.md) второй и третий раз (то есть пройдя этот [BitNode](bitnodes.md) заново).
Максимальный уровень улучшения — 3, за исключением Source-File 12, у которого жёсткого предела нет.
