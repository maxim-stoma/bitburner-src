# Grafting

Grafting — это экспериментальный процесс, позволяющий получить эффект [аугментаций](../basic/augmentations.md) без перезагрузки организма.

Grafting доступен в VitaLife в New Tokyo, где вас встретит подозрительный исследователь с сомнительными связями.
Там за определённую сумму можно начать вживление [аугментации](../basic/augmentations.md).
Это займёт некоторое время.
По завершении [аугментация](../basic/augmentations.md) применится к персонажу без необходимости устанавливать её обычным способом.

Осторожно: некоторые из тех, кто тестировал grafting, сообщали о неопознанной вредоносной программе.
Этот вирус, прозванный `Entropy`, судя по всему, набирает силу с каждой вживлённой [аугментацией](../basic/augmentations.md), ослабляя свою жертву.

Впрочем, недавно был разработан имплант, нейтрализующий действие вируса. Лаборатория начала продавать его клиентам, хотя и по заоблачной цене.

Учтите: если отменить вживление [аугментации](../basic/augmentations.md), прогресс **не** сохранится, а потраченные деньги **не** вернутся.
