# Sleeves

Когда VitaLife представила свою технологию Persona Core, позволяющую оцифровывать сознание и переносить его в другие носители, человеческие тела превратились в простые «оболочки» (sleeves) для человеческого сознания.
Так эта технология и получила название «технология Sleeve».

Технология Sleeve открывает две игровые механики:

- Duplicate Sleeves
- [Grafting](grafting.md)

Технология Sleeve открывается в [BitNode-10](bitnodes.md).

## Duplicate Sleeves

Duplicate Sleeves — это синтоиды MK-V (синтетические андроиды), в которых скопировано ваше сознание.
Иначе говоря, эти синтоиды содержат точную копию вашего разума.

По сути, Duplicate Sleeves — это клоны, которых можно отправлять выполнять работу: работать на [компанию](../basic/companies.md) или [фракцию](../basic/factions.md), совершать [преступления](../basic/crimes.md).
Выполняя эти задачи, sleeves зарабатывают деньги, опыт и [репутацию](../basic/reputation.md).

Sleeves — самостоятельные личности, то есть у каждого свои характеристики и свой опыт.

Когда sleeve получает опыт, опыт получает и он сам, и исходное сознание игрока, и все остальные sleeves игрока.

Duplicate Sleeves **не** сбрасываются при установке [аугментаций](../basic/augmentations.md), но сбрасываются при смене [BitNode](bitnodes.md).

## Как получить Duplicate Sleeves

Есть два способа получить Duplicate Sleeves:

- Уничтожить [BitNode-10](bitnodes.md).
  Каждое прохождение даёт один дополнительный Duplicate Sleeve.
- Купить Duplicate Sleeves у The Covenant.
  Это доступно только в [BitNode-10](bitnodes.md).
  Купленные так sleeves **постоянны** (сохраняются при переходе между [BitNode](bitnodes.md)).
  У The Covenant можно купить до 5 Duplicate Sleeves.

## Синхронизация

Синхронизация показывает, насколько ваше сознание согласовано с сознанием Duplicate Sleeve.
Это число от `1` до `100`, влияющее на то, сколько опыта приносит выполнение задачи sleeve-ом.

Повысить синхронизацию можно, назначив sleeve на задачу `Synchronize`.

## Sleeve Shock

Sleeve shock показывает, насколько травмирован sleeve из-за помещения в новое тело.
Это число от `0` до `100`, где `100` — полный шок, а `0` — его отсутствие.
Шок влияет на количество опыта, получаемого sleeve-ом.

Sleeve shock медленно снижается со временем.
Ускорить снижение можно, назначив sleeve на задачу `Shock Recovery`.

Пусть `X` — коэффициент восстановления sleeve (вычисляется как `(100 - shock) / 100`), а `Y` — коэффициент синхронизации sleeve (вычисляется как `synchronize / 100`).
Если в обычных условиях задача дала бы `A` опыта, то sleeve получит `A * X` опыта.

Исходное сознание игрока получает долю опыта, набранного sleeve-ом, а именно `A * X * Y`.

Остальные sleeves тоже получают опыт, но на их прибавку влияет их собственный шок.
Пусть `Z` — коэффициент восстановления получающего sleeve. Он получит `A * X * Y * Z` опыта.

## Аугментации

Для Duplicate Sleeves можно покупать [аугментации](../basic/augmentations.md).
Для этого шок sleeve должен быть равен `0`.
Любая [аугментация](../basic/augmentations.md), доступная вам сейчас через фракцию, доступна и для Duplicate Sleeves.
Есть несколько [аугментаций](../basic/augmentations.md), которые для Duplicate Sleeve купить нельзя: NeuroFlux Governor и специфичные для [Bladeburner](bladeburners.md).

Купленная для Duplicate Sleeve [аугментация](../basic/augmentations.md) устанавливается мгновенно.
При этом характеристики sleeve тут же сбрасываются в 0 — так же, как при обычной установке [аугментаций](../basic/augmentations.md).

Стоимость покупки [аугментации](../basic/augmentations.md) для Duplicate Sleeve **не** зависит от того, сколько [аугментаций](../basic/augmentations.md) вы купили себе, и наоборот.

## Memory

Memory (память) sleeve определяет, какой будет его синхронизация после сброса при смене [BitNode](bitnodes.md).
Например, если у sleeve memory равна `10`, то при смене [BitNode](bitnodes.md) его синхронизация будет изначально установлена в `10`, а не в 1.

Повысить memory можно только покупкой улучшений у The Covenant.
Как и возможность покупать дополнительных sleeves, это доступно только в [BitNode-10](bitnodes.md).

Memory — постоянная характеристика, она никогда не сбрасывается к `1`.
Максимально возможное значение memory для sleeve — `100`.

Покупка memory не влияет на синхронизацию мгновенно: memory задаёт только стартовую синхронизацию при входе в [BitNode](bitnodes.md).
